# SmartParking

SmartParking es un proyecto para gestionar el ingreso y la salida de vehículos de un parqueadero universitario, consultar los espacios disponibles y calcular el tiempo de permanencia.

## Funcionalidades previstas

- Registrar vehículos con placa, marca y color.
- Registrar el ingreso de vehículos previamente registrados.
- Registrar la salida de vehículos con un ingreso activo.
- Consultar la disponibilidad de espacios.
- Calcular el tiempo de permanencia entre el ingreso y la salida.
- Consultar los datos y el estado actual de un vehículo mediante su placa.

## Cómo clonar el proyecto

Necesitas tener Git instalado y acceso al repositorio en GitHub.

1. Abre una terminal en la carpeta donde quieras guardar el proyecto.
2. Ejecuta el siguiente comando:

   ```bash
   git clone https://github.com/smartparking-equipo/smartparking.git
   ```

3. Entra en la carpeta del proyecto:

   ```bash
   cd smartparking
   ```

4. Abre la carpeta en tu editor para consultar los archivos del proyecto.
